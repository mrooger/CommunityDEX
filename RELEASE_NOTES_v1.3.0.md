# Community Dex v1.3.0 — Interface adaptativa e atualizações

✨ **Novidades**

- Novo subtítulo: **SUA FERRAMENTA POKÉMON**.
- Menu superior responsivo: se adapta à largura do Smart Dex, Modo Compacto e Complete Dex sem exigir rolagem horizontal.
- Nova central em **Ajustes → Atualizações**.
- Verificação automática de novas versões pelo GitHub, além do botão **Verificar agora**.
- Acesso à página do release e ao ZIP oficial quando uma versão mais nova estiver disponível.
- Mantidas as correções do detector de Shinies da v1.2.1.

🔄 **Como atualizar**

Para extensões instaladas por *Carregar sem compactação*, baixe o ZIP oficial, substitua os arquivos na mesma pasta, recarregue a extensão em `chrome://extensions` e atualize o jogo. O Chrome não permite instalar automaticamente um ZIP do GitHub nesse modo.
